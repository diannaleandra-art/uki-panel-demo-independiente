Se conectó Timbres de Romo con el formato de clientes y movimientos del panel Uki. Cada cobro cifrado confirmado genera en una sola revisión CAS el movimiento de compra y el cobro mediante efectosEnCopia. La pestaña Timbres de Romo muestra saldos del historial, permite abrir WhatsApp por clic y exige confirmar el envío real con nombre de responsable. La confirmación se guarda por pedido con CAS y evita duplicados. No se generan movimientos para pedidos de prueba, no se crea venta por abrir WhatsApp ni se modifica Uki. La carta pública, el cierre definitivo y la sincronización a dueños siguen pendientes; esta publicación es solo Preview.
